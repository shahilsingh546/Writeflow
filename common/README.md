# @sahils/medium-common

Shared Zod validation schemas and TypeScript types for the Medium app.

## Install

```sh
npm install @sahils/medium-common
```

## Usage

```ts
import {
  createBlogInput,
  signinInput,
  signupInput,
  updateBlogInput,
  type CreateBlogInput,
  type SigninInput,
  type SignupInput,
  type UpdateBlogInput,
} from "@sahils/medium-common";
```
